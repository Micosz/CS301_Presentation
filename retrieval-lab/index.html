01 / เปรียบเทียบผล

อันดับที่ค้นได้ และความครบของหลักฐาน

กำลังโหลด

ปุ่มนี้คำนวณอันดับและตัวชี้วัดใหม่จากคะแนนค้นคืนที่ Python รันจริงและบันทึกไว้ ไม่ได้เรียกโมเดลสร้าง embedding ใหม่ในเบราว์เซอร์

Recall = สัดส่วนหน่วยหลักฐานเฉลยที่พบ · MRR = ค่าเฉลี่ยส่วนกลับของอันดับหลักฐานแรก ภายใน top-k · ครบทุกหลักฐาน = สัดส่วนคำถามที่พบเฉลยครบทุกหน่วย ใช้หน่วยรายวิชา/นโยบาย ไม่ใช่จำนวน chunks

02 / ตรวจรายข้อ

คำถาม เฉลย และสิ่งที่ค้นเจอ

บันทึกการตรวจอยู่เฉพาะเบราว์เซอร์นี้ การกดตรวจแล้วไม่เปลี่ยนเฉลยหรือผลชุดกลาง ส่งออกให้ทีมตรวจร่วมกันก่อนแก้ชุดข้อมูล

03 / สร้างผลทดลองใหม่

รันโมเดลผ่าน Python

เปิดตัวรันในเครื่องด้วย python scripts/server.py จากโฟลเดอร์ retrieval-lab แล้วใช้ URL ที่โปรแกรมแสดง เพื่อสร้างเวกเตอร์และคะแนนใหม่ หน้าเว็บออนไลน์แสดงผลรันที่เผยแพร่ไว้

กำลังตรวจตัวรันในเครื่อง…
